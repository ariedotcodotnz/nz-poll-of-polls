> **Archived.** This folder holds the original R / Stan / `{targets}` implementation of the NZ Herald
> 2023 Poll of Polls, kept for reference. It is no longer maintained and no longer runs as-is: the
> Electoral Commission CSV endpoints it downloads are now behind a JavaScript challenge and the
> Wikipedia tables have changed. The maintained Python implementation for 2026 lives in the repository
> root (see `../README.md`).

# Poll of polls

Source code of the NZ Herald Poll of Polls for the 2023 election. 
For more go [here](https://nzherald.github.io/nzh-poll-of-polls/) (Not currently working)
